# Development Roadmap

## Phase 1 — Working local MVP
- [x] Load enquiry register and search/filter.
- [x] Transporter contact directory.
- [x] Multiple offers per load.
- [x] Load status tracking.
- [ ] Automated tests and CI workflow.

## Phase 2 — Operations
- [ ] Login, roles, and audit trail.
- [ ] Customer master and transporter vehicle master.
- [ ] Assign transporter, vehicle, and driver to a load.
- [ ] Trip milestones, exceptions, and proof of delivery.
- [ ] CSV import/export.

## Phase 3 — Finance
- [ ] Customer receivables and transporter payables.
- [ ] Advance and balance tracking.
- [ ] Payment due reminders and reconciliation.
- [ ] Profitability by load, route, and transporter.

## Phase 4 — Network and deployment
- [ ] Controlled external transporter access.
- [ ] Quote submission and owner approval workflow.
- [ ] Notifications and mobile-friendly screens.
- [ ] Production database, HTTPS, backups, monitoring, and deployment pipeline.

## Release gate

Do not enable public user registration, expose a public load board, or store real customer/driver data until authentication, authorization, validation, privacy controls, and operational backups have been reviewed.
